# PneumoGuard AI

**Veritas AI International High School Hackathon 2026 · AI + Health**

**Research question.** Can an uncertainty-aware image classifier reduce incorrect automatic decisions compared with a standard forced-choice classifier, and what is the trade-off in manual review workload?

**Problem and data.** This educational review-prioritization experiment uses official 28×28 grayscale PneumoniaMNIST images: 4,708 training, 524 validation, and 624 test images (234 Normal, 390 Pneumonia). Labels remain 0 = Normal, 1 = Pneumonia. Pediatric origin, low resolution, class imbalance, and restricted population limit generalization. Benchmark annotations are not independent clinical confirmation. Private scans are never accepted.

**Method.** The baseline always predicts the training-majority label, Pneumonia. A 55,041-parameter PyTorch CNN has two convolution layers (16/32 channels) and a classification head. Training images update weights; validation loss selects the checkpoint. The full Colab run used seed 2026, CPU, and 20 epochs; epoch 20 was best. Forced choice uses threshold 0.5. Scores are not calibrated medical probabilities.

**Original contribution.** A validation-only grid search selects two thresholds: scores below the lower threshold favor Normal; scores at or above the upper threshold favor Pneumonia; others trigger review. The rule maximizes coverage subject to empirical accepted-image error ≤5%, with deterministic tie-breaking and an all-review fallback. This is not a safety guarantee. The policy is frozen before test evaluation. The contribution connects abstention, errors, and review workload in a documented experiment and notebook explorer.

**Measured results.** On **624 test images**, the CNN achieved **82.85% accuracy** (517 correct), **77.56% balanced accuracy**, and Pneumonia precision/recall/F1 of **79.06% / 98.72% / 87.80%**. It made **5 false negatives and 102 false positives**, with confusion matrix `[[132,102],[5,385]]` (reference rows and predicted columns: Normal, Pneumonia). The majority baseline achieved 62.50% accuracy and 50.00% balanced accuracy. Validation selected **low = high = 0.5**, so abstention produced **100% coverage (624/624), 0 reviews, and exactly the same 107 errors (17.15%)**. No Normal or Pneumonia images were abstained. **Abstention provided no improvement.** Accepted-only metrics equal whole-test metrics here because all images were accepted. The validation error was 3.44% (18/524); the 5% validation target did not guarantee test performance. The [original report](../results/report.md), [predictions](../results/test_predictions.csv), and [figures](../results/README.md) preserve the measurements.

**Limits and failures.** The archived audit records **8 distinct shared byte-identical image hashes between training and validation**, and zero with test. This overlap and validation reuse for checkpoint/policy selection may make validation estimates optimistic. Patient independence cannot be verified without patient IDs. One seed on one small benchmark provides no clinical validation. Five actual mistakes are shown; `test:1` is reference Normal but predicted Pneumonia (score 0.9999144). We cannot infer a clinical cause from this image.

**Evidence.** All 17 [Colab archive](../PneumoGuard_full_20261115T094604_549333Z.zip) files, including trained weights, were preserved in `results/`; hashes and metrics were audited without retraining or inference. The existing notebook supports independent reproduction; running all cells trains again. The executed notebook is absent from the archive. Submission remains manual.
